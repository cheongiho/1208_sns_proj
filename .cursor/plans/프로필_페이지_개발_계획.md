# 프로필 페이지 개발 계획

## 개요

PRD.md의 프로필 페이지 요구사항과 기존 컴포넌트 구조를 기반으로 프로필 페이지를 구현합니다. 사용자 정보, 통계(게시물/팔로워/팔로잉), 게시물 그리드를 표시하고, 팔로우 기능을 통합합니다.

## 현재 상태

- ✅ 데이터베이스: `users`, `posts`, `follows` 테이블이 생성되어 있음
- ✅ 뷰: `user_stats` 뷰가 생성되어 있음 (게시물 수, 팔로워 수, 팔로잉 수)
- ✅ 타입 정의: `User`, `UserWithStats`, `PostWithUserAndStats` 타입이 정의되어 있음 ([lib/types.ts](lib/types.ts))
- ✅ 게시물 조회 API: GET /api/posts에 `userId` 파라미터 지원 (이미 구현됨)
- ✅ Sidebar: 프로필 링크 생성 로직이 구현되어 있음 ([components/layout/Sidebar.tsx](components/layout/Sidebar.tsx))
- ❌ 사용자 정보 조회 API: GET /api/users/[userId] 아직 구현되지 않음
- ❌ 팔로우 API: POST/DELETE /api/follows 아직 구현되지 않음 (TODO 9번과 연관)
- ❌ 프로필 페이지 컴포넌트: 아직 구현되지 않음

## 구현할 항목

### 1. API 라우트 구현

#### 1-1. 사용자 정보 조회 API
**파일**: `app/api/users/[userId]/route.ts` (새 파일 생성)

- 동적 라우트로 개별 사용자 정보 조회 처리
- URL 파라미터에서 `userId` 추출
- `user_stats` 뷰에서 사용자 통계 조회
- `users` 테이블에서 사용자 기본 정보 조회
- 인증된 사용자의 팔로우 상태 확인 (isFollowing)
- UserWithStats 형식으로 응답 반환
- 에러 처리 (사용자 없음, DB 에러 등)

**응답 형식**:
```typescript
{
  data: {
    id: string;
    clerk_id: string;
    name: string;
    created_at: string;
    posts_count: number;
    followers_count: number;
    following_count: number;
    isFollowing?: boolean; // 현재 사용자가 팔로우 중인지 여부
  }
}
```

**참고 패턴**: [app/api/posts/route.ts](app/api/posts/route.ts)의 사용자 정보 조회 로직 참고

#### 3-3. 구성 요소
- **프로필 이미지**:

- **사용자명**: Bold, 큰 폰트
- **통계**: 
  - 게시물 수, 팔로워 수, 팔로잉 수
  - 클릭 가능 (향후 모달 열기, 1차 제외)

- **팔로우 버튼**: 
  - 다른 사람 프로필: FollowButton 컴포넌트 사용
  - 본인 프로필: "프로필 편집" 버튼 (1차 제외, Clerk 기본 사용)
- **메시지 버튼**: 다른 사람 프로필에만 표시 (1차 제외, UI만 준비)
- **이름 및 소개**: fullname, bio (1차 제외, Clerk 기본 정보 사용)

### 4. PostGrid 컴포넌트

#### 4-1. 기본 구조


## 추가 고려사항

### 게시물 그리드 vs PostFeed

**옵션 1: PostFeed 재사용**
- PostFeed 컴포넌트에 `gridMode` prop 추가
- 그리드 레이아웃으로 렌더링
- 장점: 코드 재사용, 일관성
- 단점: PostFeed가 복잡해질 수 있음

**옵션 2: PostGrid 독립 구현**
- PostGrid를 별도 컴포넌트로 구현
- PostFeed와 유사한 데이터 페칭 로직
- 장점: 관심사 분리, 유연성
- 단점: 코드 중복 가능성

**권장**: 옵션 2 (PostGrid 독립 구현) - 관심사 분리 및 유지보수성

### 게시물 상세 모달 연동

- PostGrid의 게시물 클릭 시 PostModal 열기 (TODO 7번과 연관)

- 통계 숫자 클릭 시 팔로워/팔로잉 목록 모달 열기 (1차 제외)

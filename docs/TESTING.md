# 테스트 가이드

## 개요

이 문서는 Mini Instagram 프로젝트의 반응형 테스트 및 기능 검증을 위한 체크리스트를 제공합니다.

## 반응형 테스트

### 테스트 화면 크기

다음 화면 크기에서 테스트를 수행합니다:

- **Mobile**: 320px, 375px, 414px (iPhone SE, iPhone 12/13, iPhone 14 Pro Max)
- **Tablet**: 768px, 1024px (iPad, iPad Pro)
- **Desktop**: 1280px, 1920px

### 테스트 도구

#### Chrome DevTools 사용

1. Chrome 브라우저에서 개발자 도구 열기 (F12)
2. 디바이스 툴바 토글 (Ctrl+Shift+M)
3. 화면 크기 선택 또는 커스텀 크기 입력
4. 다양한 디바이스 프리셋 선택

#### 실제 디바이스 테스트

- 실제 스마트폰 및 태블릿에서 테스트 권장
- 다양한 브라우저에서 테스트 (Chrome, Safari, Firefox)

## 반응형 레이아웃 테스트 체크리스트

### 1. 레이아웃 구조

#### Mobile (< 768px)
- [ ] Header가 상단에 표시됨 (60px 높이)
- [ ] Sidebar가 숨겨짐
- [ ] BottomNav가 하단에 표시됨 (50px 높이)
- [ ] Main Content가 전체 너비 사용
- [ ] PostCard가 전체 너비 사용

#### Tablet (768px ~ 1023px)
- [ ] Icon-only Sidebar가 좌측에 표시됨 (72px 너비)
- [ ] Header가 숨겨짐
- [ ] BottomNav가 숨겨짐
- [ ] Main Content가 Sidebar 옆에 배치됨
- [ ] PostCard 최대 너비 630px 유지

#### Desktop (≥ 1024px)
- [ ] Full Sidebar가 좌측에 표시됨 (244px 너비)
- [ ] Header가 숨겨짐
- [ ] BottomNav가 숨겨짐
- [ ] Main Content가 Sidebar 옆에 배치됨
- [ ] PostCard 최대 너비 630px 중앙 정렬

### 2. PostCard 반응형 동작

- [ ] 이미지가 1:1 정사각형 비율 유지
- [ ] 헤더 영역이 모든 화면 크기에서 정상 표시
- [ ] 액션 버튼이 터치하기 쉬운 크기 (최소 44px)
- [ ] 텍스트가 가독성 있게 표시됨
- [ ] 캡션이 2줄 초과 시 "... 더 보기" 표시

### 3. ProfileHeader 반응형 레이아웃

#### Desktop
- [ ] 프로필 이미지 150px 원형
- [ ] 가로 배치 (이미지 좌측, 정보 우측)
- [ ] 통계가 가로로 나열됨

#### Mobile
- [ ] 프로필 이미지 90px 원형
- [ ] 세로 배치 (이미지 위, 정보 아래)
- [ ] 통계가 세로로 나열됨

### 4. PostGrid 그리드 레이아웃

- [ ] 모든 화면 크기에서 3열 그리드 유지
- [ ] 썸네일이 1:1 정사각형 비율 유지
- [ ] Hover 시 좋아요/댓글 수 표시 (Desktop)
- [ ] 터치 시 게시물 상세 모달 열기 (Mobile)

### 5. PostModal 반응형 동작

#### Desktop
- [ ] 모달 형식으로 표시됨
- [ ] 이미지 50% + 댓글 50% 분할 레이아웃
- [ ] 이전/다음 게시물 네비게이션 버튼 표시

#### Mobile
- [ ] 전체 페이지로 전환됨
- [ ] 이미지 상단, 댓글 하단 세로 배치
- [ ] 닫기 버튼이 명확하게 표시됨

## 터치 인터랙션 테스트

### 1. 더블탭 좋아요
- [ ] 이미지 더블탭 시 큰 하트 애니메이션 표시
- [ ] 하트가 fade in/out (1초)
- [ ] 좋아요 상태가 토글됨

### 2. 버튼 터치
- [ ] 모든 버튼이 최소 44px 터치 영역
- [ ] 버튼 클릭 시 즉각적인 피드백
- [ ] 터치 영역이 겹치지 않음

### 3. 스크롤
- [ ] 무한 스크롤이 부드럽게 동작
- [ ] 스크롤 성능이 양호함
- [ ] 로딩 중 스켈레톤 UI 표시
